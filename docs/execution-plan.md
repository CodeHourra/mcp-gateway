## 调度规则

- 拆分任务时明确目标、文件所有权、输入接口、交付结果与验证命令；共享基础文件由主 agent 合并。
- 开发 agent 完成后提交改动和检查证据；主 agent 集成后交由验收 agent 复核当前状态。
- 发现问题 → 指派对应开发者 → 修复 → 验收复验，直到该项通过。
- 构建、受控协议测试、真实服务、真实客户端、原生应用分别记证据等级；不能互相替代。
- 账号授权和需要真实客户端的验收条件提前列明；其余可独立推进的工作继续进行。

## 0.1.2 自动扫描与选择控件统一（2026-09-07）
