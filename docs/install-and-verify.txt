MCP Gateway 安装与实机验证（0.1.8-dev）

适用：Apple Silicon Mac，macOS 15 或以上。应用自带网关核心；运行不需要 Go、Node.js 或开发服务器，stdio 上游自己的环境仍需安装。
本包仅本机 ad-hoc 签名，未做开发者签名或 Apple 公证。以下项目交付后由我们指导你实测，打包完成不代表验收通过。每阶段发回结果后再继续即可。

第一阶段：安装、启动和菜单
1.1 从旧实例菜单退出。打开 DMG，把 MCP Gateway.app 拖入“应用程序”；已有同名应用先保留旧副本。推出 DMG，从 /Applications/MCP Gateway.app 打开。预期管理窗口、Dock 图标和菜单栏出现。已有服务应先显示本地配置和待更新状态，随后自动更新；固定安装位置后再接入客户端。
1.2 网关“运行中”后检查菜单“打开管理器”“设置…”“复制网关地址”。预期页面正确，粘贴出的地址与 Agent 接入页一致；新安装默认 127.0.0.1:17840。
1.3 红色按钮关窗，再从菜单重开，并再次打开应用。预期菜单栏仍在，关窗后 Dock 图标消失，重开后窗口与 Dock 图标恢复，没有额外独立实例。实际后台调用在 2.4 测。
1.4 空闲时点“等待调用完成后退出”。预期窗口/菜单栏消失，重开正常。此步不证明在途调用退出行为。
首次提示开发者无法验证/未公证：确认本次交付来源后，可在尝试打开后用“系统设置→隐私与安全性→仍要打开”确认此应用。没有该按钮，或提示损坏/恶意软件，先反馈原文排查。
Apple 官方说明：https://support.apple.com/zh-cn/102445
反馈：DMG 文件名、芯片/macOS 版本、安装位置、1.1–1.4 通过/失败/未测及错误提示。启动失败先停在这里。

第二阶段：真实服务和客户端
先提供可测试的服务名称/传输、客户端版本；地址、密钥和账号由你在本机填写。我们选择不改业务数据的工具。
2.1 先加本地 stdio（命令/工作目录绝对路径），再静态认证远程服务，覆盖 Streamable HTTP/SSE。“测试连接”后实际调用只读工具；预期服务可用、活动与结果对应。再用菜单停用/启用、恢复连接后重连异常服务，核对实际状态。缺少服务记未测。
2.2 用可重复授权的 OAuth 测试服务/账号，检查登录、取消、重新登录、实际调用、刷新和应用重启后调用；再由我们按提供方能力指导失效/重登/清除。取消不假报成功，异常能恢复。清除只移除本机授权，不撤销提供方网站授权；能力差异单独记录。
2.3 先打开“导入配置”，预期自动列出 OMP、Claude Code、Cursor、CodeBuddy、Codex 五个已知路径及状态，但不新增服务。对发现的来源点“检查预览”，确认应用自己的 mcp-gateway connect 条目受阻并默认跳过，然后返回、不导入。再选一个常用客户端，并依次验证其余客户端（CodeBuddy 注明 CLI/CN）。Agent 接入→配置接入或查看 / 更新配置：核对目标文件、应用路径、无关条目及范围，再备份并应用，重启客户端。接入能访问全部已启用工具，先确认范围。让客户端通过 mcp-gateway 查找工具、读参数、执行只读样例，并与网关活动核对。模型回答或配置检测不算工具成功；只批准测试所需权限，缺登录/用量许可就记录反馈。
2.4 关管理窗口后重复客户端调用，预期成功；两个客户端并发用不同输入，有状态样例由我们安排，预期目标/状态不串用。补测暂停/恢复、在途测试调用等待退出/立即停止：新调用按开关拒绝/恢复，等待完成旧调用，立即停止取消后退出。
反馈：编号、服务/传输/认证类型、客户端版本、时间、工具名、无敏感结果摘要。失败可从活动→导出诊断，按提示路径取得 diagnostics 下的 JSON；先检查服务名称等是否需遮盖。

第三阶段：系统行为
3.1 保存其他工作、记录原设置，开启并保存“登录时启动”；方便时注销/登录。预期菜单栏自动出现且原只读调用成功。之后按原偏好恢复开关。注册提示不算登录验证。
3.2 空闲时先调用，正常休眠、唤醒后再调用。预期菜单/窗口一致、连接恢复。记录休眠时长、恢复等待和是否手动重连。
3.3 检查 浅色/深色/跟随系统；后者下切换 macOS 外观再恢复原值；退出重开检查偏好保留。再检查传输/认证、Tools 来源、导入方式/来源/处理方式、发现模式/日志天数：预期均为页面内单选项，无系统下拉菜单，窄窗口文字完整。Tab/Shift+Tab 移动焦点，方向键切换同组选项，Enter/Space 操作按钮/开关，Esc 关闭确认框；预期焦点可见、数值保存正确。
反馈：3.1–3.3 通过/失败/未测、前后状态及必要的遮盖截图。

统一反馈：步骤｜通过/失败/未测｜时间｜预期与实际差异。
附 DMG 文件名和“设置→关于”版本；校验值见交付消息。没测的项目继续记未测。
不要发送密钥、Token、Cookie、授权回调 URL、完整客户端配置或原始备份。账号只在你自己的浏览器/客户端登录。
数据目录：~/Library/Application Support/MCP Gateway/。换包/排错先保留该目录和钥匙串，不靠删配置重试。移动应用后要重新预览更新客户端路径。

0.1.7 管理体验复验
A. 导入页选择配置文件：应用内按钮及未选择提示应为中文；选中后显示文件名，Tab 可到达选择控件。
B. MCP 服务默认收起工具，点击“展开工具”查看；“配置详情”独立打开连接与认证，收起后回到工具列表。窄窗口详情应可见。
C. 切换 JSON 配置可编辑全部 MCP，顶层为 mcpServers 数组。先校验预览，再备份保存；移除需勾选确认。已有 ${stored:…} 标记保留原值，替换可修改，删除字段可清除配置。切换页面保留草稿；应用退出不保留未保存草稿。
D. Agent 标识来自当前客户端配置，不表示在线。旧应用路径显示需更新，客户端禁用另行标识，同名外部条目显示冲突。解除前先预览，只移除网关条目，保留其他配置与钥匙串凭证；正在运行的客户端需重新加载。

0.1.8 服务层级与 Agent 分组
服务卡片默认收起。“展开工具”显示缩进工具区，“配置详情”独立管理连接与认证；收起保留工具参数和结果。
Agent 按已配置接入、需处理、待接入分组计数。绿色标识正常接入；需更新、客户端禁用、冲突和不可读单独提示。已有独立 MCP 配置或导入来源不代表接入网关，配置状态也不代表在线。
