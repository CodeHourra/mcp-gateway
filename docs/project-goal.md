# MCP Gateway v1 项目目标

状态：用户已批准并设为执行目标；本地实现及受控验收已完成，按新增要求交付 DMG 后继续用户实机验收，完整验收尚未完成。
日期：2026-09-06；DMG 交付与用户配合验收要求更新于 2026-09-07。
依据：[产品审核稿 v0.2](product-review.md)、[需求与技术方向](requirements-and-direction.md)、[开源项目核验](research-existing-projects.md)。

## 总目标

交付一款可在当前 Apple Silicon Mac 上安装运行的个人 MCP 桌面管理器：集中收拢多个 agent 的 MCP 配置，统一管理本地和远程 MCP 的连接与认证，通过一个本机网关入口提供工具能力，支持渐进发现，并完成桌面交互、真实 MCP 与客户端联调验收。

交付结果包括源代码、可复现的构建方式、本地 DMG 安装包（包含 `.app`）、使用说明和验收报告。DMG 跳过开发者签名与公证，应用保留本机 ad-hoc 签名，不依赖开发者证书。需要用户配合的测试在交付安装包后，由用户安装并按指引逐项验证；完整完成标准不变，不能以可点击设计稿、模拟登录或编译通过代替。

## 本次审核包含的实施基线

以下基线已随本目标获批；Wails 与核心的具体版本仍由 P1 实测锁定。执行分工和证据见[实施记录](execution-plan.md)。

| 项目 | 建议基线 |
| --- | --- |
| 平台 | 首版本机 macOS / Apple Silicon；个人使用，不做团队或项目隔离 |
| 桌面技术 | Wails v3 + Vue 3 + TypeScript；锁定具体版本，首先验证菜单栏与生命周期。v3 的 Beta 风险已在产品审核稿说明 |
| 网关核心 | 优先复用 MCPProxy Go 的独立核心和管理 API；避免重复实现已有协议、OAuth 和工具发现。首阶段验证接口、许可证和打包复用边界，确认后固定版本 |
| UI | 以 v0.2 设计稿为实现基线：服务列表 + 服务详情；Tools、连接与认证、活动；独立导入页；Light / Dark / 跟随系统 |
| 菜单栏 | macOS 原生状态菜单；复杂编辑和登录放在主窗口 |
| 生命周期 | 关闭主窗口后继续常驻；主动“退出并停止网关”才停止本应用拥有的运行进程。有未完成调用时先等待，允许用户另选立即停止 |
| 客户端 | OMP、Claude Code、Cursor、CodeBuddy、Codex；按实际版本实现配置适配并记录验证结果 |
| MCP 能力边界 | 首版必须完成 tools 的聚合与发现；其他 MCP 能力按实际支持情况列明，不宣称所有能力均可透明代理 |

Wails 或核心若存在无法小改解决的阻碍，先给出已验证的缺口、替代方案及对目标的影响，再调整该基线；不在未说明的情况下换技术栈或缩减必要功能。

## 必须交付的功能

| 编号 | 交付范围 | 验收要点 |
| --- | --- | --- |
| G01 | MCP 服务管理 | 添加、编辑、移除、启用/禁用、测试连接与重连；支持 stdio、Streamable HTTP、旧版 SSE；命令、参数、工作目录和服务地址可配置，状态可辨识 |
| G02 | 配置收拢与合并 | 先只读扫描五个目标客户端的已知配置路径，同时支持文件导入、粘贴和目标客户端格式适配；扫描不自动应用；显示来源、新增、重复与冲突；比较完整连接身份，不仅比较服务名称或 URL；可合并来源、保留两份或跳过；写入前预览差异，保留备份并可恢复 |
| G03 | 认证与凭证 | 无认证、Bearer Token、API Key、自定义 Header、stdio 环境变量、上游 OAuth；支持多组 Header / 环境变量；OAuth 登录、取消、刷新、重启恢复、重新登录和清除本地授权；提供方需要时可配置 Client ID / Scopes |
| G04 | 服务内 Tools 与全局工具目录 | 真实工具名称、说明、参数类型、必填项和 schema；按服务筛选、搜索、启用/禁用、调用及结果/错误查看；目录未更新时明确标记缓存或不可用 |
| G05 | 统一网关与渐进发现 | 目标客户端连接统一入口；初始只暴露固定少量发现/调用工具，按需取 schema；提供普通聚合兼容模式；名称冲突不串路由，最终调用仍执行禁用与权限检查 |
| G06 | 桌面 UI 与菜单栏 | 实现 v0.2 的整体页面和三种主题，偏好持久化；菜单包含状态、待处理事项、打开管理器、服务启用/禁用、暂停新调用/恢复、重连异常服务、复制地址、设置和退出 |
| G07 | 排错与本机设置 | 连接与调用活动、真实目标、耗时和错误、脱敏诊断导出；本机监听、网关与管理接口认证、凭证安全存储、登录启动、日志保留、当前版本与手动检查更新 |
| G08 | 可运行交付 | 本地 DMG（包含 `.app`）、必要运行资源、构建与安装/测试说明、配置备份/恢复说明、问题排查与验收报告；原生菜单、后台运行与真实 MCP/agent 联调通过 |

实现约束：

- 上游凭证只用于对应服务；管理接口凭证、agent 接入凭证和上游凭证分开。存储方式在首阶段核验，普通配置导出与日志不包含明文凭证。
- OAuth 的提供方能力、注册方式和刷新行为分别验证；“清除本地授权”与“撤销提供方授权”使用准确的不同语义。
- 相同连接需要考虑认证、参数、环境、工作目录和传输方式。不同账号不能因 URL 相同而被合并。
- 普通模式与渐进模式使用稳定且符合所支持 MCP 版本的工具目录规则；搜索不能把工具禁用或权限校验绕过去。
- 多 agent 并发要验证有状态 MCP 的会话边界；不把“统一入口”理解成可以任意共享浏览器、事务等运行状态。
- 保留上游工具错误、结构化结果和所支持的内容类型；大型结果不静默截断。
- UI 覆盖空列表、无搜索结果、配置格式错误、导入冲突、凭证过期、端口占用、启动失败、连接断开与重试。

## 推进顺序

| 阶段 | 工作与交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| P1 技术闭环验证 | 核验并锁定 Wails 和核心版本；跑通 Vue 窗口、原生菜单、核心启动/退出、管理 API；完成 stdio、静态认证 HTTP、OAuth 的最小连接；确认客户端适配与凭证存储边界 | 存在真实可运行路径，核心复用与生命周期方案可行；重大缺口已处理或调整基线 |
| P2 网关与数据能力 | 服务配置、认证生命周期、导入/去重/恢复、工具目录与调用、渐进发现、权限边界；留下针对关键行为的可运行检查 | 真实协议调用通过，错误路径与数据保存检查通过，前端可调用稳定管理接口 |
| P3 完整桌面体验 | 将 v0.2 交互连接真实数据，完成认证表单、导入向导、Tools、活动、主题持久化和菜单栏 | 主窗口和菜单操作实际生效，状态一致；无只展示成功但未执行的占位操作 |
| P4 客户端联调与修正 | 逐个验证五个目标客户端，至少两个并发；验证真实 OAuth、同名工具、有状态会话、断线恢复和上下文暴露；修复验收问题 | 对照下表逐项通过，未验证项不标记完成 |
| P5 本地应用交付 | 打包 DMG，完成可独立执行的安装包检查，交付说明、版本清单、构建命令和验收报告；指导用户安装后完成需要配合的原生及真实服务/客户端检查 | DMG 可安装；完整目标仍要求所有必需验收通过，应用可以按说明启动和使用 |

批准后按 P1 → P5 连续推进，阶段结束更新进度、证据、缺口与下一步。正常实现与修复无需逐阶段重新审批；有证据表明需要实质改变目标或基线时，再集中说明。

## 最终完成标准

以下均为待执行验收，不是当前完成结果。

- [ ] 本机 `.app` 可启动；反复打开主窗口只保留一个受管核心；关闭窗口仍可通过网关调用；退出按约定结束受管进程，不误停外部进程。
- [ ] 登录启动、休眠唤醒、异常核心退出、端口占用有可理解且可恢复的行为；菜单状态与主窗口一致。
- [ ] stdio、Streamable HTTP、旧版 SSE 的真实协议调用通过；至少包括一个本地 MCP、一个静态认证远程 MCP和一个真实 OAuth MCP。
- [ ] OAuth 首次登录、取消、刷新、重启后恢复、凭证失效与重新授权经过验证；报告区分真实提供方实测与受控异常测试。
- [ ] 五个目标客户端的配置适配和接入逐项有结果；至少两个真实客户端同时通过网关发现并调用，工具路由与会话不串用。
- [ ] 导入重复连接可以合并来源；更换凭证、参数或工作目录会保留差异；原配置及无关字段不丢失，备份可恢复；无有效选中项时不能假报导入成功。
- [ ] 服务与单工具禁用在最终调用处生效；绕过搜索直接调用也不能成功；一个上游异常不拖垮其他服务。
- [ ] 使用同一工具目录比较普通与渐进模式，记录初始暴露工具数、schema 字节、任务调用成功、额外轮次和耗时；渐进模式不随上游工具数增加而完整暴露全部 schema。
- [ ] 只有具备 tokenizer 或模型 usage 数据才报告 token 数；不把 schema 字节或宣传百分比写成实测 token 节省。
- [ ] Tools、认证选择、导入流程、活动与菜单都连接真实行为；Light、Dark、跟随系统三种主题及持久化通过原生应用检查。
- [ ] 凭证存储、接口认证、日志脱敏、结构化/大型结果处理与关键错误路径检查通过。
- [ ] 源码、构建和使用说明、应用产物、实际版本/服务/客户端验收矩阵、已知边界齐全。

需账号登录、真实服务或客户端安装条件的验收，在相应阶段列出具体待办并请用户配合。先交付本地 DMG，让用户安装后按[安装与测试说明](install-and-verify.md)逐项验证；条件缺失时标为待验收，不能以模拟测试代替并宣告整个目标完成。

## 本轮不纳入的范围

- 团队管理、项目隔离、云同步、工具市场、任意代码执行器、统一安装/升级所有上游 MCP。
- Windows / Linux / Intel Mac 适配、自动更新下载与安装。
- 对外发布、开发者签名与公证、推送上游、替换 `/Applications` 中现有应用。
- 自动迁移用户正在使用的全部 agent 配置。产品提供差异预览和备份，真实迁移按具体选择执行。
